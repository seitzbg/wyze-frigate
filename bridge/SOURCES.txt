go2rtc binary with a patched build.

third_party/ holds the license files of the Go modules both programs are
built from. LICENSE.wyze-bridge and THIRD_PARTY_NOTICES.wyze-bridge.md are
the bridge's own.

The bridge's gwell-proxy is built from code vendored in the bridge source
(internal/gwell/upstream). Upstream describes its license two ways: that
directory's README says GPL, and the bridge's THIRD_PARTY_NOTICES.md says
MIT. Its full source is in the bridge source tarball.

Complete source for both programs, with every Go module vendored, is
attached to each release at https://github.com/seitzbg/wyze-frigate/releases
